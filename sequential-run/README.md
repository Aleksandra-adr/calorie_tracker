> **Снимок на 25 августа 2026, не текущее приложение.** Это отдельный прогон той же
> задачи для сравнения «параллельно vs последовательно» (см. корневой
> [`../REPORT.md`, раздел 5](../REPORT.md)) — код здесь не обновлялся вместе с основным
> проектом (нет поиска продукта, нормы, недельной выгрузки). Рабочее приложение —
> в корне репозитория, см. [`../README.md`](../README.md).

Та же задача, что и в основном проекте, но выполненная **одним агентом последовательно,
без субагентов** — для сравнения с параллельным прогоном. Разбор времени и контекста —
в [REPORT.md](REPORT.md).

## Как запустить

```bash
pip install -r requirements.txt
uvicorn api.main:app --reload
```

В другом терминале — фронтенд:

```bash
cd frontend && python -m http.server 8533
```

Открыть `http://localhost:8533/index.html`.

Тесты:

```bash
pytest tests/test_calculations.py -v
```

Дневной отчёт:

```bash
python workflows/daily_report.py --date 2026-08-25 --source api --api-base-url http://localhost:8000
```

## Структура

Те же четыре части, что в параллельной версии, но написаны одним потоком работы,
одним и тем же контекстом: `models/`, `storage/`, `api/`, `calculations/`,
`tests/test_calculations.py`, `frontend/`, `workflows/`.
